# 源代码来源审计

[English](PROVENANCE.md)

本页说明 Sparse-DFT 源代码与两种常用平面波程序（VASP 6.4.1 和 Quantum ESPRESSO 7.5）比对的方法和结果。本页只陈述技术事实，不作法律结论。许可边界见 [`LEGAL.zh-CN.md`](LEGAL.zh-CN.md)。

## 1. 比对对象

| 语料 | 内容 | 作用 |
|---|---|---|
| Sparse-DFT 1.0.0 | `src/` 和 `tests/native/` 中的 C++ 内核；Python 包、测试和脚本；文档 | 被审计的源代码树 |
| VASP 6.4.1 | 许可发行版的 Fortran、C 和 Python 源代码 | 参考 |
| Quantum ESPRESSO 7.5 | Fortran、C 和 Python 源代码 | 参考 |
| Eigen 3.4.0、Qbox、ASE 3.29.0 | 与 Sparse-DFT 没有共同来源的 C++ 和 Python 代码 | 阴性对照（噪声基线） |
| Qbox `PBEFunctional.cpp`；QE 的一个 f2c 文件；用脚本转写成 C 的 40 个 QE 文件 | 已知有共同来源的代码 | 阳性对照（灵敏度） |

参考源代码只由本地离线统计脚本作为数据读取。报告只保留统计量、文件名和行号，不含任何参考代码或注释文字。最后一步泄露检查把每份报告的每一行与参考注释和代码逐一比对。

## 2. 方法

1. **文字**：比较注释、字符串、docstring 和文档的 6 词组。同时出现在对照语料中的片段视为通用表述。
2. **数值表**：比较连续 5 个以上的非平凡数值字面量，分有序和无序两种比较。整数、短尾数、简单分数和 π 的倍数不计。其余匹配逐一与公开常数核对。
3. **结构**：
   - 语言无关记号流和算术骨架上的 winnowing 指纹。
   - 按稀有度加权的标识符序列 n-gram（n = 3、4、5）。
   - 函数与例程配对，用三项指标打分：骨架相似度、标识符 3-gram 包含率、最长公共标识符子序列。每一对都与 40 个规模相近的随机参考例程的第 95 百分位比较。
   - 代码行的完全匹配和近似逐字匹配（记号相似度 ≥ 0.7）。
4. **标识符**：标出与参考程序内部名称相同的代码名，以及引用参考例程或源文件名的注释。公开文件格式关键字不计，包括：
   - INCAR 标签，POSCAR、POTCAR、OUTCAR、vasprun.xml、PROCAR、DOSCAR、EIGENVAL 的字段；
   - UPF 的 `PP_*` 标签。
5. **声明与数据**：检索版权和许可声明，Numerical Recipes、libxc、FFTW 源代码，以及 POTCAR 或 UPF 数据块，并检查测试数据。
6. **第三方文件**：Eigen 头文件逐个与上游 3.4.0 比对哈希。GUI 图标与五套开源图标库比对：Feather、Lucide、Tabler、Bootstrap Icons、Material Design Icons，共 26,556 个 SVG 文件。

每项结构指标的噪声基线取阴性对照达到的最大值。只有 Sparse-DFT 的得分超过该基线时才标记。

## 3. 本发行版的结果

审计对象是本包实际分发的文件：136 个 C、C++、CUDA 和 Objective-C++ 文件（24,555 行），133 个 Python 文件（30,781 行），以及文档。除另行说明外，下表各项均为 Sparse-DFT 与 VASP 6.4.1 和 Quantum ESPRESSO 7.5 的比对。

| 检查 | 结果 |
|---|---|
| 文字（6 词组） | 没有任何注释、docstring 或文档片段复现参考文字。剩余的匹配是公开的输出表头（PROCAR 轨道顺序）、[`LEGAL.zh-CN.md`](LEGAL.zh-CN.md) 引用的 Quantum ESPRESSO 与 pslibrary 许可措辞、参考文献中的论文标题，以及通用短语。 |
| 数值表 | 分发代码中有 12 行与参考程序共享 5 个以上非平凡数值字面量。这 12 行都是公开发表的数值：PW92 和 PBE 参数、PW92 自旋插值常数 $2^{4/3}-2$，以及 Gauss–Legendre 节点和权重（§4）。 |
| Winnowing 指纹 | 最大区域：4（C++ 对 VASP）、6（C++ 对 QE）、5（Python 对 VASP）和 12（Python 对 QE）个指纹。阴性对照对 VASP 达到 4–8，对 QE 达到 4–12。12 个指纹的区域是一个 3×3 行列式（晶胞体积）。逐字转写可以被检出：40 个机器转写的 QE 例程中有 31 个达到至少 8 个指纹。 |
| 标识符序列（n = 5） | 对 VASP 最高 6.43，对 QE 最高 5.0；对照分别达到 6.42 和 27.7。6.43 的区域是一个测试程序中的合成三重循环，只覆盖所匹配参考区域的 6 %。 |
| 例程配对 | 81 对 Sparse-DFT 函数与计算相关量的 VASP 例程，每对都与 40 个随机 VASP 例程的第 95 百分位比较。55 对在每项得分上都不超过基线。4 对只在骨架相似度上超过基线，超出 0.002–0.045，且没有超过基线的共同标识符序列。19 对只在标识符重合上超过基线，3 对在两方面都以小幅超过（见下文）。 |
| 完全一致与近似逐字的代码行 | 在 413 个候选片段中，完全一致的行为 0，近似逐字的行（记号相似度 ≥ 0.7）为 0。 |
| 参考程序内部名称 | 分发的标识符和注释中没有 VASP 或 Quantum ESPRESSO 的例程名、数组名或源文件名。剩余的匹配是公开格式名称（vasprun.xml、PROCAR，以及 LASPH、NLSPLINE 等 INCAR 标签）、可选的 `vasp_legacy` 单位模式、`parse_vasprun_bands` 等互操作函数，以及 `multi` 等通用词。 |
| 声明与数据 | 分发代码中没有第三方版权声明，也没有 Numerical Recipes、libxc 或 FFTW 源代码；FFTW 只通过其公开 API 调用。19 个测试数据文件不含 POTCAR 正文，也不含 VASP 版权文字。 |
| Eigen | 337 个头文件全部与上游 Eigen 3.4.0 逐字节一致。 |
| GUI 图标 | 30 个图标，在五套图标库（26,556 个 SVG 文件）中都没有整体一致的图标。 |
| 泄露检查 | 7,728 行报告中含参考文字的行数为 0。 |

**标识符重合。** 与计算同一量的例程之间的标识符重合，主要来自公式的标准符号：DLMF §34 的 $j_1, j_2, j_3, m_1, m_2, m_3$ 和 $l_1, l_2, L, M$，以及径向网格的循环下标 $r, k, i, j$。重合最多的是 Wigner 3j 函数、Gaunt 表构建函数及其测试（对 VASP 的 Clebsch–Gordan 与 Gaunt 例程），以及球对称单中心密度（对 VASP 的径向势例程）。只改名这些符号后，最长公共标识符子序列从 16–42 降到 0–6，落在 3–10 的基线之内。

**两项都超过基线的配对。** 有 3 对在骨架上超过基线 0.01–0.05，在标识符上超过 2–26 个：
- 实球谐 Gaunt 求和（骨架 0.42，基线 0.39；共同标识符 6 个，基线 4 个）；
- 三次样条（0.40，基线 0.35）。独立的 Qbox 样条与同一 VASP 例程的得分更高（0.48）；
- 球对称单中心密度（0.26，基线 0.25），其共同标识符就是上述循环下标。

**公式内核。** 计算教科书公式的内核采用各自的写法：
- Wigner 3j 符号：由 Racah 公式（DLMF 34.2.4）得到的二项式系数交错和。对代码用到的所有参数，它与阶乘形式相差不超过 $7\times10^{-17}$。
- 倒空间投影子表：四点 Lagrange 三次插值。这些函数与 VASP 投影子例程的骨架相似度为 0.03–0.14，各自低于其基线（0.11–0.20）。
- 三次样条：以节点斜率为未知量求解（Hermite 形式）。
- 对数网格上的径向 Simpson 权重：按节点到外端的距离逐点赋值（骨架 0.22，基线 0.41）。

## 4. 共同的公式与常数

有些数值和公式在 Sparse-DFT 和参考程序里都会出现，原因是二者实现的是同一套已发表的方法。这类匹配属于预期：

- PW92 关联和 PBE 交换关联参数：Perdew & Wang, Phys. Rev. B 45, 13244 (1992)；Perdew, Burke & Ernzerhof, Phys. Rev. Lett. 77, 3865 (1996)。
- Gauss–Legendre 节点和权重（n = 12 和 16），与 `numpy.polynomial.legendre.leggauss` 相差不超过 5.2e-16。
- Wigner 3j 符号和实球谐 Gaunt 系数，取自 NIST 数学函数数字图书馆（DLMF）§34.2 和 §34.3 的闭式公式。
- CODATA 常数。可选的 `vasp_legacy` 单位模式使用较早的 Bohr 半径和 Rydberg 值（0.529177249 Å、13.605826 eV），以便与 VASP 输出比较数值。
- 自然三次样条、四点 Lagrange 插值和 3×3 行列式。
- 公开的输出格式，例如 PROCAR 的轨道列顺序。Sparse-DFT 按此格式写文件，使常用工具能够读取。

## 5. 局限

- 统计检查能发现文字、数值表、结构和名称的复制，但不能证明代码是独立编写的。如果一段转写把所有名称和运算顺序都改掉，其得分会接近噪声基线。
- 图标比对只覆盖五套图标库，不能排除其他来源。
- 本次审计只针对本发行版。之后的贡献在审阅时检查（见 [`CONTRIBUTING.md`](../CONTRIBUTING.md)）。
